# RealityBreak — a Chrome extension that makes websites break reality

Name suggestion: **RealityBreak** (folder: `reality-break`). Tagline: "The web was too stable anyway."

Positioning: a **personal fun toy first** (amaze yourself, screen-record for TikTok/Reels) with an opt-in **prank mode** (quiet icon, delayed start) — the extension never runs uninvited by default. Zero legality concerns: it only modifies the user's own pages, on the user's command, fully reversible.

## Architecture (all known territory — same patterns as your last two extensions)

```
manifest.json          MV3, <all_urls> content script, storage, activeTab
content/engine.js      Effect engine: dispatcher + revert system
content/effects/*.js   One module per effect (gravity, melt, trails, dodge,
                       mirror, bsod, portal, bleed, boss)
content/overlay.css    Base styles for overlays (Shadow DOM per effect)
popup/                 Control center: master switch, per-effect toggles,
                       intensity slider, site allowlist, "UNLEASH" button
background.js          Cross-tab chaos bus + Konami/shortcut handling
lib/store.js           Settings + revert journal
tools/test-page.html   A page full of elements/images/buttons/videos to test on
```

## The 9 effects — implementation + guards

| Effect | How | Guard |
|---|---|---|
| **Gravity flip** | Pick up to ~30 visible elements (never `input`/`textarea`), run a small rAF physics sim — velocity, gravity direction flip, bounce, settle. Auto-revert after 6s | Element cap; skips form fields |
| **Images melt** | SVG filter (`feTurbulence` + animated `feDisplacementMap`) applied to visible `<img>`s — classic wax melt | One shared `<svg>` defs block; max 20 images; 8s duration |
| **Neon mouse trails** | Full-screen fixed canvas overlay; glowing tapered strokes (`globalCompositeOperation: "lighter"`) that fade; pointermove-driven | Canvas pauses when tab hidden; devicePixelRatio-aware |
| **Dodge buttons** | Buttons within 120px of cursor translate away with a spring transition, clamped to viewport | Excludes inputs; max 15 buttons; 5s duration then spring home |
| **Tabs "bleed"** | Chaos bus: `chrome.runtime.sendMessage` broadcasts the effect to all tabs — every open tab plays an "ink wave" overlay in sequence, making tabs feel connected | Off by default; user enables "sync across tabs" |
| **Infinite mirror videos** | For each visible `<video>`: a side canvas draws mirrored frames on a rAF loop (drawImage from the playing video), creating the recursive mirror look | Skips DRM/protected videos; canvas pauses when hidden |
| **Fake BSOD flash** | Fixed overlay styled like a crash screen ("REALITY.EXE has stopped being real") for exactly 0.2s | Rare random timer only in chaos-mode; never more than once per 2 min |
| **Portal swallows an element** | Animated swirl ring (CSS/SVG) spawns near a random visible element; the element scales/rotates/blurs into it, portal collapses | Element restored on revert; journal records original state |
| **Boss mode (Konami ↑↑↓↓←→←→BA)** | All effects cascade with ramping intensity + a HUD score counter; entering the code again ends it | Master volume of chaos = intensity slider |

## Control & safety (what keeps store review + users happy)

- **Summoned-only by default**: chaos runs only via the popup's big "UNLEASH" button, keyboard shortcut, or Konami code. Optional "random chaos timer" (off by default) and a **prank mode** (subtle icon label, delayed start 30s) are opt-in toggles.
- **Revert journal**: every effect records the original state it touched; one "Restore reality" button (and Escape key) undoes everything. Effects also auto-revert on a timer.
- **Site allowlist/blacklist** in the popup; sensitive pages never auto-run (nothing runs unless summoned anyway).
- **Performance guards**: element caps per effect, rAF loops pause on hidden tabs, `prefers-reduced-motion` honored (simpler effects).
- **Storage schema**: `settings {enabled, effects: {gravity: true, ...}, intensity, syncTabs, chaosTimer, sites: {allowlist, blocklist}}`.
